# 영양사 국시 문제풀이

제50회 영양사 국가시험(2026년 12월 19일) 대비 개인용 문제풀이 사이트입니다. 태블릿 기준으로 설계했습니다.

이 저장소에는 **암호화된 사이트만** 들어 있습니다. `index.html`의 내용(문제·코드·화면)은 AES-256-GCM으로 암호화되어 있고, 비밀번호를 입력해야 브라우저에서 풀립니다. 원본 코드는 저장소에 올리지 않습니다.

## 구조

```
index.html             암호화된 사이트 (tools/build.mjs가 생성)
tools/loader.html      비밀번호 입력 화면 + 복호화 코드 (index.html의 틀)
tools/build.mjs        src/ 원본을 암호화해 index.html을 만드는 스크립트
sw.js, manifest.webmanifest, icon.svg   홈 화면 추가·오프라인
src/                   원본 (.gitignore, 작성자 컴퓨터에만 있음)
```

## 다시 배포하기 (원본이 있는 컴퓨터에서)

```powershell
$env:PREP_PASSWORD='비밀번호'; node tools/build.mjs
```

그다음 `index.html`을 커밋하고 GitHub Desktop에서 Push 하면 1~2분 뒤 사이트에 반영됩니다.
비밀번호를 바꾸려면 다른 값으로 빌드하면 됩니다(태블릿에서 한 번 새로 입력해야 함).

## 암호화 방식

- 키: PBKDF2-SHA256(비밀번호, 16바이트 salt, 1,000,000회) → AES-256-GCM
- 비밀번호가 틀리면 복호화 자체가 실패합니다. 소스에는 비밀번호나 그 해시가 없습니다.
- 숫자 8자리 비밀번호는 경우의 수가 1억 개라서 6자리보다 100배 강하지만, 시간을 들여 기계로 대입하면 풀릴 수 있습니다. 더 안전하게 하려면 영문+숫자 10자 이상으로 바꾸세요(이때 입력 화면은 숫자 패드 대신 키보드를 쓰도록 수정 필요).
